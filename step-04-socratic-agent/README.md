# Step 04 — Socratic Study Mentor Agent (`data/[area]/`)

Builds a multi-turn Google ADK `LlmAgent` (`socratic_study_mentor`) that uses the `search_area_content` tool over `data/[area]/` and guides the student with hints and a single follow-up question.

## Run in CLI
```bash
cd step-04-socratic-agent
npm start javascript
```

## Launch Google ADK Web UI (`adk web`)
```bash
cd step-04-socratic-agent
npm run web
# Opens ADK DevTools Web UI at http://localhost:8000

# Or from the root folder:
npm run step04:web
```

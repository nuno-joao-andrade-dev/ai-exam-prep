# Step 5: Live Rubric Grading & Web Server (`step-05-grading-complete`)

Evaluates open-ended student answers against the Analytic Rubric and launches the Web Server for the React Question Interface.

## Run Step 5 (CLI)

```bash
cd step-05-grading-complete
node index.js javascript
# Or pass another area folder:
node index.js ai-agents
node index.js cloud
```

## Launch Web Server

```bash
cd step-05-grading-complete
node server.js javascript
```

# Step 3: Autonomous Exam Generator (`step-03-exam-gen`)

Synthesizes Multiple-Choice Questions, an Open Analytical Question, and an Analytic Rubric from `data/[area]/[content files]`.

## Run Step 3

```bash
cd step-03-exam-gen
node index.js javascript
# Or pass another area folder:
node index.js ai-agents
node index.js cloud
```

# Step 1: Google ADK + Ollama / Gemma 4 Setup (`step-01-setup`)

Connects Google's Agent Development Kit (`@google/adk`) to a local **Gemma 4** model served by **Ollama** (`127.0.0.1:11434`) using plain JavaScript.

## Run Step 1

```bash
cd step-01-setup
node index.js javascript
# Or pass any folder from ../data/[area]:
node index.js ai-agents
node index.js cloud
```
